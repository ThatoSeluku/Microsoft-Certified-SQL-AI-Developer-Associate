\# Project 01 — Sales Order Optimization Lab



\## Objective



Build a small relational sales database to demonstrate practical SQL development, database design, and query optimization skills.



\## Scenario



A fictional company sells products to customers across multiple regions.



The database will contain:



\* Customers

\* Products

\* Sales Representatives

\* Orders

\* Order Items



\## Skills Demonstrated



\* Relational database design

\* Primary and foreign keys

\* Constraints

\* T-SQL

\* Joins

\* Aggregations

\* Common Table Expressions

\* Window functions

\* Views

\* Stored procedures

\* User-defined functions

\* Indexing

\* Execution plan analysis

\* Query optimization

\* Transactions and error handling
